## About

I build fully custom Discord bots: no templates, no recycled code — every project is designed from scratch around what the server or client actually needs. I also build websites to round out your projects.

- **Ticket systems** — support channels, transcripts, automated replies

- **Server management** — welcome messages, reaction roles, leveling
- **Websites** — landing pages, dashboards, bot/site integration
